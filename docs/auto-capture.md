# 自动记账

自动记账默认关闭。打开之后，用无障碍服务在本机识别支付页面，弹出确认单再写入账本。原来的微信、支付宝通知解析留作补充，已有的设置、草稿和商家分类都还在。

## 会读什么

无障碍服务的 `packageNames` 只有：

- `com.tencent.mm` 微信
- `com.eg.android.AlipayGphone` 支付宝
- `com.unionpay`、`com.unionpay.uppay` 云闪付

只认简体中文的支付成功页和账单详情。密码节点（`isPassword`、控件 id 或类名里带 password）整棵丢掉，不进入解析。聊天、待确认的转账、关闭或失败的订单直接忽略。

银行短信是单独开关，默认关闭。只处理新收到的短信广播，以及短信应用通知里的正文，不读取短信信箱。验证码会丢掉。

页面文字、短信正文和金额都只在本机解析。不会上传。已经配置过的 AI 助手如果开着，并且商家对不上本机分类，才会把商家名称和分类名单发给你自己的接口，用来猜一个分类。没配 AI 也能记账。

## 确认单

悬浮窗上可以改支出、收入或转账，以及账户和分类，然后「记下」「稍后」或「忽略」。稍后放进原来的待确认。一分钟内相同金额会提示，不会静默记两笔；如果待确认里已经有这一笔，记下会确认那一条。

小米 HyperOS 的支付保护会挡住支付页面上的悬浮窗。这种情况下先留着，离开微信、支付宝或云闪付后再弹出，状态栏里也会有一条可以点开的通知。服务配置仍然只包含上面的支付包名，离开页面是靠「当前窗口已经不是这些包」来判断，不会去读桌面或其他应用的内容。

## 规则放在哪

用词在 `PaymentPageRules`，页面解析在 `PaymentScreenParser`，短信在 `BankSmsParser`。微信或支付宝改版时，改这些列表，并在 `PaymentScreenParserTest` 里加一条文本树。夹具用缩进文本，`pwd:` 开头的行表示密码节点。

## 限制

- 只适配简体中文。英文或繁体界面认不出。
- 页面用词一变，成功页可能暂时认不出。通知补充仍可以生成待确认。
- 支付宝香港、云闪付以外的银行 App 不在范围内。
- 银行短信只覆盖常见大陆银行模板。有的手机只把短信交给默认短信应用，这时要靠短信通知，并且通知补充和银行短信都要开着。
- 聊天里如果整段出现「支付成功」和金额，仍可能误识别。密码页和很长的聊天列表会丢掉。
- 连续两笔完全相同的金额，需要先处理完上一张确认单。
- 转账是否该记成「转账」还是「支出」，页面上常常分不清，确认单上可以改。
- 无障碍、悬浮窗、通知、忽略电池优化、自启动和锁定最近任务都要用户自己允许。关掉应用里的开关后不再读取页面；系统无障碍里的服务需要用户再关一次才会从系统设置里消失。
