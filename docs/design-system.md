# 牛牛记账视觉系统

高端、克制、耐看。浅色像暖瓷与象牙，深色像石墨与墨蓝，香槟金只出现在关键数字、选中态和极细描边上。交互短而清楚，目标是中端机滑动与点击保持 60fps，任何交互帧不低于 30fps。

## 色彩

对比度按 WCAG AA（正文至少 4.5:1）核对。收支沿用中文习惯：支出偏红、收入偏绿，但饱和度压低。应用内没有单独的「红绿对调」开关。

金色在浅色背景上使用 `#6E5128`（对象牙约 6.4:1，对结余卡底约 5.5:1）。深色主题的金色 `#D4B483` 对石墨约 9.5:1。

## 字体

不打包额外字体，避免增大 APK。使用系统无衬线，靠字重和字距分层。

- 大额数字：`displaySmall` / `displayMedium`，字重 Light，负字距，`tnum` 等宽数字。
- 标签：`labelLarge` / `labelMedium` 增加 0.6–1.1sp 字距，接近小型大写的节奏。
- 金额组件统一 `fontFeatureSettings = "tnum"`。

## 形状与表面

- 圆角：10 / 14 / 18 / 24 / 28 dp。
- 卡片：无投影，色调抬升一层，0.5dp 发丝描边。
- 分割线：0.5dp，低对比发丝色。
- 渐变只用于首页结余卡，垂直、同色相、两端色差很小。滚动内容不用模糊、不用大面积半透明。
- 分类图标：细线描边，放在低透明度的圆形底上。

## 动效与触感

- 时长：200ms（按键、淡入）与 280ms（切页、月份、图表入场）。缓动 `FastOutSlowInEasing`。
- 顶栏分页滑动不再对整页做 alpha，避免滑动时的大透明层。
- 键盘、保存、底部「记一笔」和确认操作使用轻触感（`KEYBOARD_TAP`）。
- 点击目标至少 48dp。删除流水、忽略草稿后用底部条提供撤销。

## 图标

启动图标与闪屏保留牛与金币，改为深墨底上的细线浅色形象，并提供单色层。通知小图标仍为白色剪影，保证状态栏可读。

## 性能约定

- 列表使用 `key` 与 `contentType`。首页、明细、编辑器状态以及流水、分类、账户模型标记 `@Immutable`。`compose_stability.conf` 将 `java.time`、不可变 `List` 和 `NavHostController` 视为稳定，避免滑动和输入时的重组风暴。明细行的点击回调按 id `remember`。键盘回调按 ViewModel `remember`，按键缩放走 `graphicsLayer`。
- 按键缩放走 `graphicsLayer`，不触发布局。
- 保持 R8 与 `app/src/main/baselineProfiles/baseline-prof.txt`。
- `:macrobenchmark` 测量冷启动、四页横滑、约 500 条明细滚动、打开记一笔并输入金额。说明见该模块测试类注释。
